# Basic Conditional Formatting

## Dataset
Superstore Sales Dataset

## Objective
To highlight the top and bottom sales values automatically and improve report readability.

## Work Completed
- Used the Superstore Sales Dataset.
- Created a separate Formatting Sheet.
- Applied conditional formatting to the Sales column.
- Highlighted the top 10 sales values in green.
- Highlighted the bottom 10 sales values in red.
- Created a separate Rules List sheet.

## Tools Used
- Google Sheets

## Outcome
Learned how to use conditional formatting rules to identify the highest and lowest sales values automatically.
